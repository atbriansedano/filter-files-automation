## **Filter Files Automation**

A Windows desktop tool that automatically organizes files from your Downloads and Documents folders. It sorts each file into its own folder — based on file type and date — inside your Documents directory, so you never have to manually clean up a messy folder again.

### **Features**
- 🖥️ Simple GUI — built with Python's tkinter, no command line needed
- ➕ Add multiple folder paths — choose any folders you want scanned (e.g. Downloads, Desktop)
- ⚡ One-click execute — hit the "Execute" button and the script does the rest
- 🗂️ Auto-sorting by file type — .pdf, .jpg, .docx, etc. each get their own folder
- 📅 Auto-sorting by date — files are further organized by the date they were created/modified
- 📦 Standalone executable — no need to install Python to run it
### **How It Works**
- Open the app (either the .exe or by running the Python script).
- Use the GUI to add the folder path(s) you want to organize.
- Click Execute.
The script scans each folder you added, then moves the files it finds into a new folder inside your Documents directory, sorted by file type and date.
